# ecommerce-data-purchase-analysis
📊 Pandas Data Analysis Project
📌 Overview

This project uses Python Pandas to explore and analyze a transactional dataset, extracting meaningful insights from customer and purchase data.

🛠️ Tools Used
Python
Pandas

🔍 Key Analysis
Dataset exploration (rows, columns, data types, null values)
Purchase statistics (min, max, average)
Filtering based on language, job title, and credit card provider
Email extraction using IP address and credit card details
Analysis of purchase timing (AM vs PM)
Email domain popularity
📊 Insight

The dataset reveals clear patterns in customer behavior, email usage, and purchasing trends, showing how data can be transformed into actionable insights using Pandas.

🚀 Impact

Helps in understanding real-world data cleaning, filtering, and analysis for better decision-making.
